Administração e publicação

Importe arquivos CSV ou Excel, inclusive local.xlsx com KM, LATITUDE e LONGITUDE. Cada importação substitui somente a categoria selecionada. Os dados importados ficam na memória desta página até a exportação.

Importação de bases

Para o previsto, importe diretamente CURVA MODEL R1.xlsx (ID, Attività, QtaTotale, UM, Inizio, Fine, PercCosto). Teste: escolha Cadastro de efetivo, selecione o Excel de mão de obra e clique em Importar arquivo. Depois confira o total de registros abaixo.

Aceita Excel (.xlsx), CSV ou JSON. Para o cadastro de efetivo, usa a aba EFETIVO_FUNCIONARIO. Os dados ficam nesta página até exportar o HTML.

Publicação

O botão gera um novo HTML completo com as bases incorporadas. Publique o arquivo como index.html no GitHub Pages. O visitante abrirá os indicadores imediatamente, sem importar nada.

Atenção: todo dado incorporado ao HTML publicado poderá ser acessado por quem receber o link, inclusive nomes e matrículas. Publique apenas dados autorizados. O botão de administração não é proteção de acesso.
