# ICCR Dashboard - Publicação GitHub Pages

## ATENÇÃO: DADOS PESSOAIS
O arquivo `index.html` é a versão V49 ORIGINAL e contém nomes, matrículas e apontamentos de colaboradores. **Não publique este pacote em repositório público sem autorização da empresa e revisão de privacidade.** GitHub Pages de repositório público torna os dados acessíveis a terceiros. Para testar sem expor dados, use um repositório privado e verifique as condições de publicação do seu plano, ou remova os dados pessoais antes da publicação.

## Publicação
1. Crie um repositório `dashboard-iccr` no GitHub.
2. Faça upload do conteúdo desta pasta (inclusive `.github/workflows/pages.yml`) na raiz do repositório.
3. Em Settings > Pages > Build and deployment, selecione GitHub Actions.
4. Após o workflow concluir, acesse `https://SEU-USUARIO.github.io/dashboard-iccr/`.

## Atualizações
Substituir `index.html` por uma nova versão e enviar um commit na branch `main` publica no MESMO endereço. Este pacote NÃO implementa importação automática de Excel/CSV, sincronização com SIMOVA ou edição persistente pelo navegador. A versão V49 é um HTML estático com dados incorporados. Alterações locais no navegador não atualizam o site para os demais usuários.

## Escopo
Este pacote não altera cálculos, abas, filtros ou aparência da V49; apenas prepara sua publicação estática.
